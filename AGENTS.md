# Tehom

Read docs/master-spec.txt before changing product scope. Rust and GPUI Kit; no web application shell, SaaS or AppImage. Publishing integrations are Instagram Reels through crates/tehom-instagram (native Rust port of the private mobile API, no Python or daemon) and TikTok through crates/tehom-tiktok (the person signs in to TikTok in their own Chromium-based browser window; uploads and the post request are made from that logged-in page; never implement or vendor TikTok request signatures such as X-Bogus or _signature). YouTube Shorts is shown as unavailable and must not be claimed to work. TikTok is experimental and has not been run against the live service with a real account; say so until that is done. Keep shared media work outside UI callbacks. Never claim platform runtime validation from compilation alone. Missing source logo must not be redrawn. Preserve existing user files and publish exports only after successful validation. Run cargo fmt --check, cargo clippy --workspace --all-targets and cargo test --workspace; record unavailable checks honestly.
