# Asset provenance

`brand/icon.svg` is an unchanged copy of the user's explicitly supplied `logo(2).svg`, matching the 512×512, 2.7 KB geometric knot described in the product specification and the prior SVG delivery. SHA-256: `99899e8643d4ad5c5f1503baf17783e1f43918df1491c591f1fd79e7c0074d30`. Its viewBox, path data and evenodd fill rule are preserved. `icon-dark.svg` changes only currentColor to the light Oxocarbon foreground for README display on dark backgrounds.

Geist-Regular.ttf and GeistMono-Regular.ttf: https://github.com/vercel/geist-font (regular TTFs from fonts/Geist/ttf and fonts/GeistMono/ttf), downloaded 2026-11-03. Included under fonts/OFL.txt. No font files were modified.

`readme/os-apple.svg`, `readme/os-linux.svg` and `readme/os-windows.svg` are simplified monochrome platform glyphs drawn for this README to label the install commands. The other `readme/*.svg` cards are generated by `readme/generate.py` and embed the brand mark unchanged.

`icons/instagram.svg`, `icons/youtubeshorts.svg` and `icons/tiktok.svg` are unchanged monochrome brand glyphs from Simple Icons (CC0 1.0), downloaded 2026-11-09 from https://cdn.jsdelivr.net/npm/simple-icons@v13/icons/instagram.svg, …/youtubeshorts.svg and …/tiktok.svg. The brand names and marks remain trademarks of their owners; they only label the posting buttons.

Platform app icons (`brand/icon-tile.svg`, `brand/hicolor/{16,24,32,48,64,128,256,512}.png`, `brand/icon.ico` with 16–256 px, `brand/icon.icns` with 16–1024 px including @2x) are generated from `brand/icon.svg` by `python3 assets/brand/generate-icons.py` on 2026-11-10 with Python 3.14, rsvg-convert 2.63.3 and ImageMagick 7.1.2-34. The mark's path is copied unchanged (the script asserts the path data matches `icon.svg`), coloured #161616 and placed by a scale-about-centre transform on a white (#ffffff) rounded tile with a faint #dde1e6 edge; macOS gets Apple's ~10% outer margin. Output is byte-for-byte reproducible with the same tool versions.
