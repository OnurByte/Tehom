# Asset provenance

`brand/icon.svg` is an unchanged copy of the user's explicitly supplied `logo(2).svg`, matching the 512×512, 2.7 KB geometric knot described in the product specification and the prior SVG delivery. SHA-256: `99899e8643d4ad5c5f1503baf17783e1f43918df1491c591f1fd79e7c0074d30`. Its viewBox, path data and evenodd fill rule are preserved. `icon-dark.svg` changes only currentColor to the light Oxocarbon foreground for README display on dark backgrounds.

Geist-Regular.ttf and GeistMono-Regular.ttf: https://github.com/vercel/geist-font (regular TTFs from fonts/Geist/ttf and fonts/GeistMono/ttf), downloaded 2026-11-03. Included under fonts/OFL.txt. No font files were modified.

`readme/os-apple.svg`, `readme/os-linux.svg` and `readme/os-windows.svg` are simplified monochrome platform glyphs drawn for this README to label the install commands. The other `readme/*.svg` cards are generated by `readme/generate.py` and embed the brand mark unchanged.
