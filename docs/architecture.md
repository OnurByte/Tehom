# Tehom

Rust workspace. Native GPUI Kit 0.8.1 desktop; shared Rust engine will serve CLI and headless service. SQLite persistence, argument-based FFmpeg/ffprobe/yt-dlp invocation. No shell interpolation, web frontend, mandatory account or telemetry.

First gate: native video preview and real MP4 export. Full application work follows evidence from this prototype. Platform support requires actual Linux, macOS and Windows checks, not cross-compilation alone.
