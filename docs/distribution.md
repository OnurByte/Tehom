# Distribution

No published release, updater or signed package exists yet. `packaging/linux/build-deb.sh` builds an unsigned Debian package (`target/deb/tehom_<version>_<arch>.deb`) with both binaries, a desktop entry, the logo recoloured only (geometry verified identical), licences and example configuration. It declares FFmpeg, yt-dlp and GStreamer base/good/libav as dependencies rather than bundling them. It has been built and inspected on Arch Linux but not installed on Debian or Ubuntu. One-command installers: `install.sh` (Linux and macOS: `curl -fsSL https://raw.githubusercontent.com/OnurByte/Tehom/main/install.sh | sh`) and `install.ps1` (Windows: `irm …/install.ps1 | iex`). They download `tehom-<os>-<arch>` archives from GitHub Releases, verify SHA-256, install for the current user only (`~/.local/bin` with a desktop entry, `~/Applications/Tehom.app`, or `%LOCALAPPDATA%\Programs\Tehom` with PATH and a Start menu shortcut) and offer, after asking, to install FFmpeg, yt-dlp and GStreamer. `.github/workflows/release.yml` builds those archives on `v*` tags with `packaging/release-archive.sh` and smoke-tests each packed CLI. Evidence on 2026-11-07: `install.sh` piped through `sh` into an isolated HOME installed both binaries, the desktop entry and icon, reported missing GStreamer plug-ins, and refused a tampered checksum without installing; `install.ps1` has not been run (no PowerShell on the test host); the release workflow has not run and no release is published yet.

The native-prototype CI builds Linux x64, Windows x64 and both macOS architectures, runs real-media tests and captures native windows. Artifacts are development evidence, not signed distributable packages. Inspect screenshots and logs before recording the preview gate as passed.

Release work after the gate must provide user-scope, integrity/signature-checked installation, versioned updates and rollback; deb, Flatpak, dmg and Windows exe; runtime bundling and license notices; real clean-install/uninstall checks. AppImage and web shells remain excluded.
