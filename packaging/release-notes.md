## Install

**The easy way.** Paste one command. It downloads the right file, checks it is not damaged, adds Tehom to your apps and tells you if FFmpeg, yt-dlp or GStreamer are missing.

macOS and Linux, in **Terminal**:

```sh
curl -fsSL https://raw.githubusercontent.com/OnurByte/Tehom/main/install.sh | sh
```

Windows, in **PowerShell**:

```powershell
irm https://raw.githubusercontent.com/OnurByte/Tehom/main/install.ps1 | iex
```

**Or download the files yourself.**

| Your computer | Download |
| --- | --- |
| Windows | [tehom-windows-x86_64.zip](https://github.com/OnurByte/Tehom/releases/download/@TAG@/tehom-windows-x86_64.zip) |
| Mac with an M chip (M1 or newer) | [tehom-macos-aarch64.tar.gz](https://github.com/OnurByte/Tehom/releases/download/@TAG@/tehom-macos-aarch64.tar.gz) |
| Linux, Intel or AMD | [tehom-linux-x86_64.tar.gz](https://github.com/OnurByte/Tehom/releases/download/@TAG@/tehom-linux-x86_64.tar.gz) |
| Linux, ARM | [tehom-linux-aarch64.tar.gz](https://github.com/OnurByte/Tehom/releases/download/@TAG@/tehom-linux-aarch64.tar.gz) |

A Mac with an Intel chip has no download yet. Each file has a `.sha256` checksum beside it in the list below.

These downloads are not code-signed or notarised, so your computer may warn you the first time. On Windows choose **More info**, then **Run anyway**. On a Mac, right-click Tehom and choose **Open**. The paste commands avoid the Mac warning.
